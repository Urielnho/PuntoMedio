# Referencias de PuntoMedio

- `technical/PuntoMedio_Documento_Tecnico_V1.docx`: copia sin modificaciones del documento indicado por el usuario.
- `stitch/`: copia de la carpeta exportada indicada por el usuario, con siete HTML y un sistema de diseño Markdown.
- `solicitud-etapas.md`: instrucciones del alcance y de la secuencia de trabajo.
- `manifest.json`: inventario y huellas SHA-256 de las fuentes copiadas.

El documento técnico se leyó mediante su contenido XML, incluidas sus tablas. No se editó el DOCX ni se evaluó su maquetación como una nueva entrega documental. Los HTML se inspeccionaron como texto: no se ejecutaron scripts, CDN ni aplicaciones para renderizarlos.

Las referencias documentan intención y presentación. Sus ejemplos de usuarios, códigos, reputación, actividad y conexión no acreditan datos reales ni funcionalidades implementadas.
