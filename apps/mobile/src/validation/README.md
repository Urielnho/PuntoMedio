# Validaciones pendientes

La Etapa 1 prepara controles visuales y tipos, sin validar una cuenta real ni enviar información. Las reglas de registro, teléfonos, contraseñas, archivos y errores de API deberán implementarse cuando se autorice la etapa correspondiente.

El servidor será la autoridad del correo y teléfono verificados, del perfil completo y de los permisos. Un borrador local, una fotografía o rellenar una casilla no otorgan autorización para operar.

La pantalla SMS conserva las seis casillas del diseño. No emite mensajes ni comprueba códigos. Los códigos de recogida y entrega son otra entidad, vinculada a cada servicio y con controles de uso y expiración en el backend.
