# Rediseño UI/UX — Aplicación completa

## Sistema compartido

- Las superficies usan radios discretos y se eliminaron bordes de tarjetas no esenciales.
- Los estados vacíos son filas editoriales compactas.
- Los estados usan un punto de color y texto, sin cápsulas decorativas.
- Las listas utilizan filas seleccionables con separadores; no duplican la selección con botones «Abrir».
- Los encabezados secundarios ya no encierran la flecha de regreso en otro contenedor.
- Las opciones excluyentes usan controles de selección compactos.

## Móvil

- Inicio y navegación: centro de acciones compacto y cinco destinos principales.
- Autenticación: identidad gráfica real, formularios jerarquizados y mensajes breves.
- Explorar, Actividad y Mensajes: estados vacíos y listados compactos.
- Perfil: identidad, datos, modo repartidor y configuración organizados como secciones.
- Perfil público: reputación, privacidad y reseñas sin tarjetas anidadas.
- Encuentros y encargos: las superficies funcionales se conservan únicamente donde agrupan datos o acciones relacionados.
- Pagos de producto: selección mediante filas, sin tres botones principales compitiendo.

## Wear OS

- Los estados se muestran sin paneles con borde.
- El contenido respeta el área segura circular y conserva componentes nativos.
- La acción contextual usa lavanda y el resto de la navegación permanece secundaria.
- El detalle sin servicio presenta una sola acción deshabilitada en vez de tres acciones competidoras.

## Límites respetados

No se modificaron contratos, lógica de negocio, autenticación, servicios Supabase, reglas de pagos ni arquitectura. No se ejecutaron compilaciones, pruebas, emuladores ni despliegues.
